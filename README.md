## التشغيل المحلي

```bash
# تطبيق POS (يبع سيرفر داخلي على http://127.0.0.1:4173)
cd pos && npm start

# نسخة سطح المكتب
cd pos && npm install && npm run electron

# لوحة الإدارة
cd admin && npm start          # → http://127.0.0.1:4180

# سيرفر التراخيص المستقل
cd license-server && npm start # → http://127.0.0.1:8787
```

> التطبيق يختار **أول منفذ فارغ** تلقائيًا (4173 ثم ما بعده)، فيمكن تشغيل أكثر من نسخة في نفس الوقت.

## تطبيق POS

- **الكاشير**: بحث فوري + باركود، تصنيفات، سلة بتعديل الكميات، خصم %، ضريبة، دفع (نقدي/بطاقة/تحويل) مع حساب الباقي، حفظ واسترجاع السلات، فاتورة حرارية 80mm تُطبع تلقائيًا
- **المنتجات**: إضافة/تعديل/حذف، تصنيف، باركود، تكلفة/سعر/كمية/وحدة، فلترة مخزون منخفض/نافد، تصدير CSV
- **التصنيفات**: إدارة كاملة بألوان
- **التقارير**: مبيعات، ربح، متوسط الفاتورة، أعلى المنتجات
- **المستخدمون**: 3 صلاحيات (مدير/مشرف/كاشير)
- **الإعدادات**: بيانات المتجر، الضريبة، حد تنبيه المخزون، نص الفاتورة، سيرفر الترخيص، نسخة احتياطية
- **اختصارات**: `F2` بحث · `F4` حفظ السلة · `F9` دفع

## لوحة المعلومات (`/dashboard/`)

5 أقسام: نظرة عامة (مقارنة بأمس) · المبيعات (يومي/بالساعة/طرق الدفع) · أداء المنتجات · المخزون (تنبيهات) · الفواتير. محمية بالترخيص وتسجيل الدخول.

## نظام التراخيص

```
العميل → لوحة الإدارة → إصدار دفعة مفاتيح → يُسلَّم المفتاح
                                        ↓
العميل يحط المفتاح في التطبيق → POST /api/activate → يُربط بالجهاز
                                        ↓
كل فتح للتطبيق → POST /api/verify → لو المفتاح ملغى/منتهي يُقفل التطبيق
```

- المفتاح: `MERO-XXXX-XXXX-XXXX` ببصمة تحقق (checksum)
- الخطط: `trial` (7 أيام) · `basic` · `pro` · `enterprise` (10 أجهزة)
- **إلغاء تنشيط جهاز** لا يسمح له بالرجوع بنفسه — يعود فقط بـ **"إعادة تنشيط"** من اللوحة
- ويب هوك مدفوعات: `POST /api/webhooks/payment` يولّد المفتاح تلقائيًا بعد الدفع

### المتغيرات المطلوبة (Vercel)
| المتغير | الوصف |
|---|---|
| `ADMIN_TOKEN` | رمز لوحة الإدارة |
| `UPSTASH_REDIS_REST_URL` / `_TOKEN` | قاعدة بيانات Redis |
| `KV_REST_API_URL` / `_TOKEN` | يُقبل أيضًا (Vercel KV) |
| `WEBHOOK_SECRET` | (اختياري) توقيع ويب هوك المدفوعات |

## البناء والنشر

```bash
# نسخة الويب
npx vercel --prod

# نسخة سطح المكتب (installer ويندوز)
cd pos
npm install
npm install-scripts approve electron    # إذا حجب npm سكربت التنزيل
npx electron-builder --win nsis --publish never

# نسخة محمولة (بدون تثبيت)
npx @electron/packager . "Mero Dev POS" --platform=win32 --arch=x64 --out=dist --overwrite --icon=assets/img/icon.ico

# لينكس AppImage
npx electron-builder --linux AppImage --publish never
```

> النشر التلقائي: أي `git push` على `main` ينشر الموقع، وأي tag (`git tag v1.0.1 && git push --tags`) يبني وينشر نسخ الويندوز واللينكس على GitHub Releases عبر GitHub Actions.

## ملاحظات تقنية

- **بدون تبعيات في الواجهة**: JavaScript خالص (ES Modules) + SVG للرسوم — لا React/Vue ولا خطوات بناء
- **التخزين**: `localStorage` في التطبيق (مع نسخ احتياطي JSON) و Redis في سيرفر التراخيص
- **الاتجاه**: RTL كامل بخط Cairo
- **الهوية**: نيون بنفسجي على خلفية داكنة
- الأصول مرفقة برقم إصدار (`?v=3`) لتفادي الكاش عند التحديثات
